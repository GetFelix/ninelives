# kernel

The pinned Linux LTS version and our config fragments. Stock upstream Linux
built from verified source, no patches, no loadable modules
([0001](../docs/decisions/0001-linux-kernel.md),
[0007](../docs/decisions/0007-kernel-from-upstream-source.md)). Each fragment
says which [requirement](../docs/requirements.md) it serves. The version is
settled in #3.
