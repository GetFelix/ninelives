A distributed operating system

A cluster that behaves like one machine.

I'm building NineLives so that the memory of a whole cluster is a log. When a machine dies, its programs carry on somewhere else, from the last record they handled.

What it is

Every change to the system is a durable, ordered record in Felix: what should run, where it runs, what each program received and what it produced. A program's state is a fold over those records, so any machine can rebuild it. That is where the name comes from.

Linux handles drivers, memory and local processes. NineLives handles what Linux can't do across machines.

  • Failover

    A dead machine's programs continue elsewhere, without lost or repeated work.

  • Time travel

    Rebuild any program as it was at any moment, then step forward one record at a time.

  • An audit trail

    Every decision the system made is on the record, in order.

The kernel is stock Linux, on purpose. Here is why.
