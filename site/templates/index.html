An operating system with the Felix log at its core.

Nothing boots yet, and most of the big choices are still open. The aim is a cluster whose memory is a log, so that when a machine dies its programs carry on somewhere else, from the last record they handled.

01 / The idea

What it is meant to be

The design is that every change to the system will be a durable, ordered record in Felix: what should run, where it runs, what each program received and what it produced. A program's state is a fold over those records, so any machine can rebuild it. That is where the name comes from.

A kernel on each machine would keep handling drivers, memory and local processes. NineLives is for what no single machine's kernel can do across machines.

  • Goal

    Failover

    A dead machine's programs continue elsewhere, without lost or repeated work.

  • Goal

    Time travel

    Rebuild any program as it was at any moment, then step forward one record at a time.

  • Goal

    An audit trail

    Every decision the system makes is on the record, in order.
